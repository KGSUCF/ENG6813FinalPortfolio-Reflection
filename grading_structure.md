# Grading Structure

The course is worth 1000 points.

| Course work | Points |
|---|---:|
| Activity Verification | 50 |
| Introduction post | 30 |
| 12 weekly low-stakes assignments, 40 points each | 480 |
| Signature assignment proposal / preliminary reading | 100 |
| Signature assignment draft / process checkpoint | 100 |
| Signature assignment final submission | 200 |
| Final reflection | 40 |
| **Total** | **1000** |

## Weekly low-stakes assignments

Most weekly assignments are worth 40 points. A typical weekly assignment includes a short individual post, analysis, worksheet, or reflection, plus peer response through Canvas discussion.

Suggested breakdown:

| Weekly component | Points |
|---|---:|
| Main post / analysis / worksheet | 30 |
| Two peer comments | 10 |
| **Total** | **40** |

## Signature assignment sequence

The signature assignment is worth 400 points total:

| Component | Points |
|---|---:|
| Proposal and preliminary reading | 100 |
| Draft checkpoint and peer review reflection | 100 |
| Final submission | 200 |
| **Total** | **400** |

This structure makes the signature assignment substantial while rewarding steady engagement throughout the course.
